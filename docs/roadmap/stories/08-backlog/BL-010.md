# BL-010: Playful AI seat names and a compact seat badge

## Metadata
- **Epic**: Backlog
- **Status**: `completed`
- **Priority**: `medium`
- **Effort**: `M` (1-2 hours)
- **Dependencies**: BL-008 (tabbed game layout), LO-008 (table chat)

## Context

Owner request (2026-11-15): "Make the default names more fun / playful. The Claude / haiku name
also takes up too much space. Maybe just an icon and then when people click on it it shows the
model?"

Before: a bot seat was "Bot 1", "Bot 2"; an LLM seat was named after its model ("Claude Haiku
5.5") and next to the name a text badge repeated the kind or the model label. In the players
table, chat, merger cards and lobby that was long and repetitive, especially on phones.

## Acceptance Criteria
- [x] **Character names.** A bot or LLM seat added without a `name` gets one of 48 short,
      original, theme-neutral money/business names (`backend/session/seat_names.py`): unique in
      the room case-insensitively, also against humans and by first word; random per room,
      deterministic under the room seed / `GAME_SEED`; `Tycoon N` when the list runs out. An
      explicit `name` wins; scripted test seats keep `Scripted N`. The model is never in the name.
- [x] **Wire format unchanged** (`name`, `kind`, `agent_label`); the rule is documented in
      `docs/architecture/seat-contract.md` ("Seat names").
- [x] **Bots play the same as before**: a bot's RNG is seeded "Bot N" (its N-th place among the
      room's bots), not by its random name, so seeded games stay reproducible.
- [x] **LLM prompts use the names.** The decision and talk prompts say "You are <name>"; the talk
      prompt adds the short name others may use ('Players may call you "Baron".') and treats a
      message naming the seat by its distinctive first word as "to you", the same rule as
      `chat.named_seats` (shared helper `seat_names.short_names`).
- [x] **Compact badge.** `SeatKindBadge` is one 22px icon (robot: rules-based bot; spark: LLM;
      code brackets: scripted), a real `<button>` whose accessible name carries the kind and model
      ("AI player, Claude Haiku 5.5", "Rules-based bot"). Click, tap, Enter or Space opens a
      popover ("AI player · <model>" + "Reads the table chat"; "Rules-based bot · does not chat");
      outside click and Escape close it. 32px hit area via negative margins, so rows do not grow.
      The popover is portalled to `document.body` with fixed, viewport-clamped positioning (flips
      above when there is no room below), so tab panels and the phone's bottom bar never clip it.
- [x] **Used everywhere seats are shown:** lobby lists (player and host), players table, chat
      authors, merger result card, trade offers, game over ranking, replay board. Inside the trade
      builder's partner buttons and the transcript seat chips (which can sit in a link) the icon is
      static (`role="img"` with the same accessible name). "BOT ASSIST xN" stays visible on its own.
- [x] **Model still spelled out** where models are chosen or compared: the lobby's Add AI menu,
      the transcript summary and seat chips (model first, character name second), the bench
      leaderboard.
- [x] **Tests.** Tier 1 `backend/tests/test_seat_names.py` (list rules, uniqueness, first-word
      clashes, exhaustion, seeding); tier 2 `test_seat_routes.py` (defaults, explicit name wins,
      scripted names, `GAME_SEED` determinism, clash refused) and the talk-prompt tests; unit
      `SeatKindBadge.test.tsx` (roles, accessible name, outside click, Escape, static variant);
      tier 3 `screens/seat-badge.spec.ts` at 390x844 and 1366x768 (tap target, row height, Enter,
      tap/click, popover fully on screen and topmost); journeys read seat names from the page.
- [x] Surface coverage map updated (PG-20, new PG-37, `SeatKindBadge`, TX-14).

## Notes / deviations

- Unit fixtures (`frontend/tests/unit/fixtures/*.json`) were regenerated with their generators;
  the generators now configure the room seed before adding seats so the names are reproducible.
- The test-mode Fake LLM's canned replies keep their fixed text ("Fake LLM heard you, ...",
  "Fake LLM here: noted."); they are fixed strings, not the seat's name.
- The bench runner names its seats "Seat 1".."Seat N" (unchanged); its pages show the model as
  the primary text anyway.
