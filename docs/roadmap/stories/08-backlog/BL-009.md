# BL-009: A tasteful visual pass (board shapes, type, turn signal, motion, palettes, light theme)

## Metadata
- **Epic**: Backlog
- **Status**: `completed`
- **Priority**: `medium`
- **Effort**: `L` (2-4 hours)
- **Dependencies**: BL-008 (tabbed game layout)

## Context

Owner feedback after BL-008 (2026-11-15): the tabbed layout works; the look should catch up. The
owner approved a list of aesthetic changes. Chain names, colours, words and board size come from
the ruleset files (`backend/rulesets/*.json`, themes `default`, `valley`, `mini`), so nothing a
player sees may be tied to one theme. Frontend and ruleset colour values only: no rule, route or
message-shape change.

Before/after screenshots (phone 390x844 Board and Chains tabs, laptop 1366x768, host 1920x1080,
home page, a valley board, light scheme) were compared for every item.

## Acceptance Criteria
- [x] **Quiet empty board.** Empty squares print a faint coordinate on a dim square (still readable,
      still in the DOM); placed tiles and the viewer's playable squares carry the contrast.
- [x] **Chains read as shapes.** Same-chain neighbours join (no gap, no inner rounding, rounded outer
      corners); the chain abbreviation shows once per chain, centred on the shape; orphans stay
      separate squares. Pure geometry from neighbours (`lib/boardShapes.ts` -> `data-join`,
      `data-anchor`), so it works for every board size, tile size and ruleset, on the player,
      host and transcript replay boards.
- [x] **Two typefaces.** System sans-serif for names, labels, chat and body text; system monospace
      for numbers, coordinates and money. No web font and no font request (the Google Fonts import
      is gone).
- [x] **"Your turn" signal.** The phase bar (`data-turn="mine"`) and the action card take an accent
      tint while the table waits on the viewer, calm otherwise; the host's phase line is the calm
      "whose turn" style with a turn marker. The words are unchanged (never colour alone).
- [x] **Motion that explains.** A placed tile settles in (220 ms); a square that changes chain (a
      merger, an orphan joining a chain) sweeps from its old colour (200 ms + up to 72 ms stagger);
      cash and net worth flash up/down (280 ms). CSS keyframes only under
      `prefers-reduced-motion: no-preference`; nothing is even marked under `reduce`. No test
      depends on timing; no test-mode switch was needed.
- [x] **Calmer chain colours** in all three rulesets: similar OKLab lightness, distinct hues, dark
      labels at WCAG AA or better, and larger colour-vision-deficiency distances than before
      (numbers below). `defaultRuleset.ts` follows `default.json`; generated fixtures regenerated.
- [x] **Tighter Chains tab.** One compact row per chain: marker line (name, size, price, bank stock,
      SAFE), chips for 1st and 2nd (names, shares -> bonus, ties, sole holder, a thin bar for their
      share of the stock), a "you" chip with shares, value and position; the viewer's rows have an
      accent edge. All seven chains fit the 390x844 phone tab without scrolling.
- [x] **Home page, favicon, light theme.** Home: a board motif in the ruleset's chain colours (SVG),
      tagline, accent CREATE / JOIN, entry cards for watch bots, games & transcripts and the bench
      (every test id kept). Neutral SVG favicon. Light scheme from the same tokens, following
      `prefers-color-scheme`, with a toggle remembered in localStorage.
- [x] **Tests**: unit (`boardShapes.test.ts`, Board/Tile shape and motion tests, `FlashValue.test.tsx`,
      `ThemeToggle.test.tsx`, PageShell/PlayerPage/HostPage turn-signal assertions, palette
      lightness and colour-vision checks over every ruleset in `tests/unit/themes.test.tsx`, home
      motif colours per ruleset); tier 3 `screens/appearance.spec.ts`. Coverage map rows H-15, H-16,
      PG-34..PG-36.

## Implementation Notes

- `Board` computes `chainShapes()` once per render; each `Tile` gets `join` and `anchor`. A square
  joined east or south grows over the grid gap with a negative margin (the grid item stretches),
  and the corners that touch a neighbour lose their radius. The anchor's label is nudged up to
  half a square towards the shape's centre, only towards a joined side.
- Motion is imperative on purpose (a data attribute set in an effect, removed on
  `animationend`): no re-render and nothing on the first paint.
- The light tokens are written twice in `styles/tokens.css` (system preference, and the manual
  `data-theme` choice); `lib/theme.ts` applies a stored choice before the first render (no inline
  script, which a strict CSP would block).

### Deviations
- **Capitals**: button labels keep their capitals (tests and players match on them, and they read
  as controls); capitals elsewhere were already limited to tab labels, the phase line and small
  section labels.
- **In-game theme toggle on phones** is hidden (the header is full of numbers there); it is on the
  home page, the wide-screen game header, the host header and the transcript/bench pages.
- **Playwright runs light now**: headless Chromium reports `prefers-color-scheme: light`, so the
  screen and journey suites run in the light scheme; `appearance.spec.ts` covers both.
- Regenerating the transcript unit fixtures picked up table chat the generator now records;
  `replay.chat.test.ts` compares later steps with the recording instead of assuming none.
