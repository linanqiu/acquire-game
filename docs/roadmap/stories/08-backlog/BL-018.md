# BL-018: One question at a time on the home page; declutter the game and the other pages

## Metadata
- **Epic**: Backlog
- **Status**: `completed`
- **Priority**: `high`
- **Effort**: `L` (3+ hours)
- **Dependencies**: BL-017 (say each thing once), BL-014 (Board tab fits 390x675)

## Context

Owner feedback (2026-11-17, phone, about 390x675): "There must be a better way to lay this out
too. For example you're always asking for name. Then give option to create new or join. And if
join ask for room code. Same for all the rest of the UI, it's very cluttered. And not just the
front page: the games pages too, and tabs."

Every screen was captured at 390x675 (dark and light) and 1366x768 before and after, and judged
against: one primary action, nothing said twice, numbers aligned, quiet secondary info, no
wrapping, touch targets of 44px or more for primary controls.

## Left as it was, and why

- **Board tab, header, tab bar.** The Board tab already fits 390x675 with one primary action
  (BL-014/BL-017). Four tabs stay: Chains, Chat and Trades each hold a full screen of content and
  the Board must not scroll. The BUYOUT wordmark stays in the in-game header (a few tests tap it
  as "somewhere else"; dropping it is a matter of taste, below).
- **Transcript viewer body.** It is a tool page with many parts (summary, seats, replay controls,
  board, decisions, timeline); a redesign needs its own story.
- **Host page lobby.** A big-screen display; only its join link was fixed.
