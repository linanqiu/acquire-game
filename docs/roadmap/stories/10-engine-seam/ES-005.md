# ES-005: Seat Driver Loop, Per-Room Lock, Remove Duplicated Bot Paths

## Metadata
- **Epic**: [Engine Seam](../../epics/10-engine-seam.md)
- **Status**: `in-progress`
- **Priority**: `critical`
- **Effort**: `L` (2-4h)
- **Dependencies**: ES-001, ES-002

## Context

Today bots and humans reach the engine by different routes, and `http_game_action` temporarily
monkeypatches a global send function to capture output. That is a concurrency hazard and the place
where bot-only bugs hide. Design: [seat-contract](../../../architecture/seat-contract.md), "Server".

## Requirements

- One per-room `asyncio.Lock` serialises all mutations (human messages, HTTP actions, driver).
- One driver loop: while the blocking decision belongs to an agent seat: build `DecisionContext`,
  `await agent.decide()` with timeout, `validate_action`, on failure fall back to the heuristic
  agent, `apply_action`, broadcast.
- Human WebSocket messages and HTTP actions go through the same `apply_action` (under the lock).
- `agents/heuristic.py` wraps `game/bot.py`; delete duplicated bot turn code in `main.py`/elsewhere.
- Remove the global send-function monkeypatch in `http_game_action`; responses and broadcasts use
  explicit return values / the room's broadcaster.
- Broadcast includes per-player `kind` (keep `is_bot`) and top-level `awaiting`.
- Trade responses for agent seats are decisions too (they are not special-cased).
- Seat management: `POST /room/{code}/add-seat`, `remove-seat/{player_id}`, `GET /agents/catalog`;
  `add-bot` stays as alias.

## Acceptance Criteria

- [ ] `grep` shows one call site of the engine's mutating methods outside `decisions.py`.
- [ ] No module-level send-function reassignment remains.
- [ ] Concurrency test: two humans and an agent submit actions simultaneously for 200 rounds; no lost updates, no double-applied actions, no deadlock.
- [ ] Game with all-heuristic seats runs to game over in-process, with the same result as before for a fixed seed (or the difference explained in the PR).
- [ ] A seat whose `decide()` hangs is timed out and falls back; other rooms are unaffected.
- [ ] Existing backend tests and e2e smoke still pass.
