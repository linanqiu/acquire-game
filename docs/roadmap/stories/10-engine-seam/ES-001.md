# ES-001: Decisions API and Single Apply Entry Point

## Metadata
- **Epic**: [Engine Seam](../../epics/10-engine-seam.md)
- **Status**: `in-progress`
- **Priority**: `critical`
- **Effort**: `L` (2-4h)
- **Dependencies**: None

## Context

Every seat (human, LLM, heuristic, scripted) must act through the same entry point, and the engine
must say who has to decide what. Specified in [seat-contract](../../../architecture/seat-contract.md),
`backend/game/decisions.py`.

## Requirements

- `pending_decisions(game)`, `legal_actions(game, decision)`, `validate_action(game, player_id, action)`
  (no mutation), `apply_action(game, player_id, action)` (single mutation entry point; never raises
  on bad input; result dict always has `success`).
- Decision kinds: `place_tile`, `found_chain`, `choose_survivor`, `stock_disposition`, `buy_stocks`,
  `trade_response`.
- Wire-format actions are exactly what `backend/main.py` accepts today.
- Existing `Game` methods remain; `apply_action` dispatches to them. Existing tests keep passing.

## Acceptance Criteria

- [x] All six decision kinds produced in the right phases; `[]` in lobby and game over.
- [x] Every action in `legal_actions` passes `validate_action` and succeeds in `apply_action` (property test over fuzzed games).
- [x] Actions not in `legal_actions` are rejected without mutating state (state compared before/after).
- [ ] Fuzz: 500+ full games (random legal choices, seeded) finish without exception.
- [x] `buy_stocks` followed by `end_turn` turn shape documented and tested.
- [x] Contract doc updated in the same commit if behaviour differs.

**Status note (2026-11-14):** all met except the fuzz volume. `backend/tests/test_decisions.py`
plays 26 seeded random full games (3-6 players: 20 via `test_random_full_game_property`, 6 via
`test_random_game_played_to_exhaustion`) with legal and illegal actions mixed in, not 500+. Either
raise the count (mark the long run `slow`) or change the criterion with a justification.

## Implementation Notes

- Do not change rules behaviour; this wraps the engine.
