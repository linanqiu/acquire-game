> **Deviations of the built harness from the text below (kept for the record):**
> it lives in `backend/bench/` (run as `python -m bench` from `backend/`), not `backend/benchmarks/`

> `null` prices (nothing invented).

## Requirements

- CLI: `python -m benchmarks.run --seats llm:<id>,bot,bot,bot --games N --seed S`.
- Plays full games through the decisions API and the same driver/agents as production.
- Seat rotation across games so position bias cancels out; fixed seeds so runs are reproducible.
- Report per seat: games, win rate, mean final net worth, mean rank, fallback rate, repair rate,
  mean/p95 latency per decision, tokens in/out, and **cost per game** (price table in config).
- Output a machine-readable JSON file and a short markdown summary.
- A `--dry-run` using the fake provider so the harness itself is tested in CI without network.
- Cost guard: refuses to start if the estimated cost exceeds `--max-cost` (default small).
