# LO-008: Public table chat; LLM seats talk and negotiate

## Metadata
- **Epic**: [LLM Opponents](../../epics/09-llm-bot.md)
- **Status**: `complete`
- **Priority**: `high`
- **Effort**: `L` (2-4h)
- **Dependencies**: LO-003 (decision loop), LO-005 (seat badges), AB-001 (transcripts)

## Context

Owner, after playing a few rounds (2026-11-15): "There should be a public chat window where ai bots
and I can talk and ai bots should probably respond eg to negotiations like oh I take majority in this
and you do that." Then: "AI opponents should be able to talk any time. Not just when they move." and
"Let's not go crazy in optimizing costs. Go for good gameplay first." Rules-based bots stay silent.

This promotes "room chat / table talk" from the Deferred list of the epic, as an owner decision
(not a benchmark result).

## Requirements

- Any seated human can post a short plain-text message to the table at any time (lobby and game,
  on or off turn), over HTTP. Everyone, including the host/spectator view, receives it over the
  WebSocket, in order, and again on reconnect. Spectators read only. Length cap and a per-player
  rate limit.
- Chat is never a game action: no `apply_action`, no change to game state, snapshots or fixtures.
  Nothing said is binding; binding deals are trade offers.
- LLM seats see the recent chat in their decision prompt (in the event timeline, as unverified
  talk) and may attach a `say` to a move.
- LLM seats may speak off-turn at any time: after any human message, after another AI's message
  that names them or negotiates, and after notable game events that concern them. Each call has
  the full decision context (own hand and holdings, standings, chains, events, chat). Silence is
  a normal answer. LLM seats may talk to each other with loop protection only (AI streak limit,
  per-seat cooldown, one call in flight, a generous per-game runaway cap); all settings.
- Talk calls never hold the room lock, never touch game state, never delay a move; their usage is
  counted and priced in the transcript totals.
- Every message is in the game transcript and the transcript viewer's timeline.
- UI: a `ChatPanel` with author name and kind badge, auto-scroll that does not yank a reader who
  scrolled up, send on Enter, unread count when collapsed, read-only with a reason for spectators;
  on phones collapsed by default and never over the board or the tile rack; shows which seats are
  AI that read the chat. Mounted with a one-element edit in `PlayerPage` and `HostPage`.

## Implementation Notes

- Server: `backend/chat.py` (messages, rate limit, triggers, loop protection, talk calls),
  `POST /room/{code}/chat/{player_id}` in `api/rooms.py`, `seats.apply_and_publish` calls
  `chat.on_action` (events, streak reset) and posts `say`. Settings in `backend/config.py`
  (`chat_*`). Agent side: `LLMAgent.reply`, `agents/llm/talk.py` (talk prompt, offline fake).
- The test-mode Fake LLM talks deterministically: replies `Fake LLM heard you, <name>: "<text>"`
  to a human (silence when the text contains "quiet"), `<name> answers <other>: deal?` to another
  AI, `<name> saw: a chain founded` after a founding, and says `FAKE_SAY` once per human message
  containing "deal" with its next move.
- Agents constructed directly (benchmark, tests with scripted providers) have `table_talk=False`,
  so a talk call never consumes a scripted decision answer and the benchmark is unchanged except
  for the prompt version (the system prompt and schema gained table talk).

### Deviations from the brief

- The first build answered only messages addressed to a seat, with a compact public-only prompt,
  forced low effort, a 20 s cooldown and 8 calls per game; replaced the same day by the owner's
  "talk any time, gameplay before cost" decision (above).
- A trade offered to an LLM seat does not trigger a separate talk call: the seat's
  `trade_response` decision already carries `say`, so a second call would only duplicate it.
- When a game ends with talk calls in flight, the transcript is closed when they finish (up to
  `chat_reply_timeout_s` + 5 s after `game_over`) so their lines and cost are recorded.

### Cost (estimate, no real model run yet)

Measured on a mid-game position: system prompt about 10 k characters (about 2.7 k tokens, cached),
decision user prompt about 10.5 k characters; ten typical chat lines add about 1 k characters
(about 250 tokens) to each decision prompt; a talk call sends about 9 k characters (about 2.4 k
uncached tokens) plus the cached system prompt, and returns a short reply (tens of tokens, plus
thinking at the seat's effort). At Claude Sonnet 5.5 prices ($2 / $10 per million, cache reads
$0.10) a talk call costs about $0.006-0.01. A game with an active human chatter and the usual
foundings and mergers gives a seat roughly 20-50 talk calls: about $0.15-0.50 per LLM seat per
game, at most about $0.60 at the 60-call cap; the chat lines in decision prompts add about $0.05.
Claude Haiku 5.5 is about 20 times cheaper; Opus 5.5 about twice Sonnet.
