# LO-011: Cut the cost of LLM seats

## Metadata
- **Epic**: [LLM Opponents](../../epics/09-llm-bot.md)
- **Status**: `completed`
- **Priority**: `high`
- **Effort**: `L` (2-4h)
- **Dependencies**: LO-003 (decision loop), LO-008 (table chat), LO-009 (playbook), AB-001 (transcripts), AB-003 (bench protocol)

## Context

Owner (2026-11-16): "LLM cost saving is back". Half a game with two LLM seats had cost about
$0.50. Target: at least 40% less per LLM seat per game, without worse or noticeably slower play.

Measure first, then cut, then replay the same games. Spend breakdown, each cut, before/after
table, quality comparison and what was dropped: [docs/ai/cost.md](../../../ai/cost.md).

## Acceptance criteria

- [x] Spend measured on real games before any change: per decision kind, uncached / cached /
      cache-write input, output (visible answer vs thinking), calls per game, retries.
- [x] Prompt caching verified from the reported cached tokens. Finding: the answer schema narrowed
      to the legal options changed on every call and each change was billed as a cache write of
      the whole system prompt. Fixed with a static schema per decision kind (one schema for all
      kinds for `json_object` providers); legality is still checked by `check_against_legal` and
      the engine.
- [x] No model call when nothing is to decide (nothing can be bought, one playable tile, one chain
      left), through the same `apply_action` path, recorded as `outcome: "forced"` in the
      transcript and shown in the transcript viewer.
- [x] Smaller per-turn prompt: compact event log, three notes, shorter state lines.
- [x] Talk calls gated by rules before any model call: a human spoke to the seat or to the table,
      or an AI seat floated a deal at the seat; game events only at the end of the game. Settings
      `chat_reply_events`, `chat_reply_table_seats`, `chat_reply_effort`.
- [x] Same games re-run (Haiku, 36 paired games; Kimi, 2 games): cost per game per seat, win rate,
      mean rank, margin, fallbacks, retries, latency. Reported with sample sizes and with a repeat
      of the baseline to show its run-to-run spread.
- [x] `PROMPT_BUILDER_VERSION` bumped (7 -> 8); tier 1/2 tests; fixtures unchanged.
- [ ] 40% lower cost per seat per game for both models: met for Haiku (-49% on decisions). Kimi's
      decision calls are 32% cheaper; with the talk calls removed a live game is estimated near
      the target, not measured.

## Notes

- Quality: the shipped version won 30 of 36 games against a pooled baseline of 40 of 48, with a
  margin about $2,700 lower (one standard error). No loss is shown; a small one cannot be excluded
  at this sample size. The same baseline code played twice on 12 games differed by more than that.
- Deviation: lower `max_tokens` and lower effort for small decisions were considered and not done
  (no or negligible saving; see the doc). A second prompt variant was measured and dropped.
- Not fixed: purchases of four shares (the only retry cause, about 1% of purchase calls). The
  sentence that addressed it was part of the dropped variant.
- The measurements were made on prompt v6 plus these cuts; v7 (position-aware trade numbers,
  LO-010) was merged afterwards and is not part of the measured games.
- No deployed setting was changed. Bench output and keys are not committed.
