# LO-002: Context Synthesis (Prompt Builder)

## Metadata
- **Epic**: [LLM Opponents](../../epics/09-llm-bot.md)
- **Status**: `in-progress`
- **Priority**: `high`
- **Effort**: `L` (2-4h)
- **Dependencies**: ES-002 (event log), ES-004 (calculator pack)

## Context

The model decides well only if it is shown what a careful human at the table would know, plus exact
arithmetic. This story builds the prompt from the `DecisionContext` in the
[seat contract](../../../architecture/seat-contract.md).

## Requirements

Inputs (all from `DecisionContext`): public event log for this viewer, calculator pack, legal
actions, the seat's own state/hand, and the decision kind.

- A system prompt: Acquire rules summary (concise), objective (maximise final net worth), output
  format, and "answer with exactly one action from the legal set".
- A user prompt with sections: current public state, calculator pack, event log (compact, most
  recent turns in full, older turns summarised mechanically by code, not by an LLM), the decision
  and its legal actions.
- An output schema per decision kind that maps directly to the wire-format action dict.
- Token budget: the prompt must stay under a configurable limit for a full game; truncation is
  done by code and is deterministic.
- **No leakage**: never include other players' hands, the tile bag order, or events with
  `private_to` set to someone else.

## Acceptance Criteria

- [ ] `build_prompt(ctx) -> (messages, schema)` is a pure function with golden-file tests per decision kind.
- [ ] A leakage test builds prompts for each seat in a fuzzed game and asserts no other seat's private tiles appear.
- [ ] Late-game prompt for a 6-player game stays under the configured token budget.
- [x] Same `DecisionContext` always yields byte-identical prompts.
- [x] Trade-response and propose-trade contexts are covered (see LO-004).

**Status note (2026-11-14):** implemented in `backend/agents/llm/prompt.py` as
`build_system_prompt()` and `build_user_prompt(ctx, notes, budget=...)` (not a single
`build_prompt(ctx) -> (messages, schema)`; the schema comes from `agents/llm/schema.py`
`build_schema`). `tests/test_llm_prompt.py` has no golden files (assertions on content), tests
leakage on one constructed game rather than fuzzed games, and the budget test uses 500 events, not
a 6-player late game. Those three criteria stay open. The prompt must expose a version (a hash of
the system prompt plus a builder version constant) for transcripts and the benchmark protocol
(AB-001, AB-005).

## Implementation Notes

- Suggested: `backend/agents/llm/prompt.py`. Format tables as plain text/JSON; keep names identical
  to wire-format names (`Tower`, `5C`) so answers need no translation.
- Do not ask the model to compute prices or bonuses; they are in the pack.
