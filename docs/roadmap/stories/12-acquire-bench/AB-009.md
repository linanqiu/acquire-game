# AB-009: First Published Results

## Metadata
- **Epic**: [Transcripts & Acquire Bench](../../epics/12-acquire-bench.md)
- **Status**: `not-started`
- **Priority**: `high`
- **Effort**: `M` (1-2h of work, plus the run itself)
- **Dependencies**: AB-004 (standalone eval), AB-006 (leaderboard)
- **Blocked by**: an API key (at least `ANTHROPIC_API_KEY`) and published per-token prices for
  every model in the run. Neither is available to the implementing agents. Do not simulate this
  with the fake provider or invent prices.

## Context

The harness exists but has never run against a real model, so there are no measured results, and
the tier defaults for the lobby (LO-001, LO-006) are unset. This story is the first real run under
`acquire-bench-v1`, published with its transcripts.

## Requirements

- Fill `backend/bench/prices.json` for each model in the run from the provider's published pricing
  page; record the page and date in the file or the results README.
- Run the protocol for each model under test (vs-baseline track) and the baseline control, with
  `--max-usd` set to a cap the owner approves. Games per matchup at least the protocol minimum
  (AB-005); if the budget does not allow it, run fewer and publish them labelled insufficient,
  not rounded up.
- Optionally run the head-to-head track for the top models.
- Commit under `docs/ai/benchmarks/<date>-acquire-bench-v1/`: the exact command lines, `report.json`
  and `report.md`, the seed list reference, prices used, total spend, and the transcripts needed to
  support every leaderboard row (or a pointer to where they are stored if size forbids git; AB-008
  governs persistence).
- State the tier defaults the results justify (strength first, then fallback/retry rates, latency,
  cost per game; the selection method is in `docs/ai/benchmarking.md`) and update the catalog
  defaults accordingly (closes the "default model per tier" criterion of LO-001).
- Update `docs/ai/benchmarking.md` and the roadmap with the outcome. Report what the numbers show
  and what they do not; no claims beyond the intervals.

## Acceptance Criteria

- [ ] `prices.json` has real, sourced prices for every model run.
- [ ] A results directory exists under `docs/ai/benchmarks/` with commands, report, prices, spend
      and transcripts (or documented location).
- [ ] The run used the standalone command from AB-004 with a protocol id; the report states
      protocol id and prompt version.
- [ ] Every leaderboard row for the run links to existing transcripts.
- [ ] Total spend is within the approved cap and is recorded.
- [ ] The leaderboard page (AB-007) shows the results from a deployed or local server.
- [ ] Tier defaults chosen and recorded with the evidence, or the story states that results were
      too thin to choose.
