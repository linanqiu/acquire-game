# TP-005: Tier-4 Journeys from the Home Page

## Metadata
- **Epic**: [Test Pyramid](../../epics/11-test-pyramid.md)
- **Status**: `in-progress`
- **Priority**: `critical`
- **Effort**: `L` (2-4h)
- **Dependencies**: TP-002

## Context

True end-to-end journeys with **no shortcuts**. They always start at the home page, use only what
a user can click and type, and never call `/api/*` or `/test/*`. This is the guard against the
failure the owner saw: tests that skipped the home page and missed many real bugs.

## Requirements

`npm run e2e:journeys`; about 5-8 tests:

1. **Full single-player game**: home -> create game -> lobby -> add AI/scripted seats -> start ->
   play real turns -> a merger -> a trade -> game over -> play again.
2. **Multi-human**: two browser contexts; host creates, second joins by room code; both play turns.
3. **Human + LLM seat**: add the fake-provider LLM seat from the lobby catalog; play until the LLM
   seat has acted, including a trade response; thinking indicator seen.
4. **Host/spectator view**: "Watch bots play" from the home page; host screen updates to game over.
5. **Reconnect/refresh mid-game**: reload the page and drop the network during play; state resumes.
6. **Error paths**: bad room code, duplicate name, full room (and empty-name validation).

Rules:
- Loop until the feature occurs (merger, trade) rather than assuming turn N; use a fixed seed
  (`ACQUIRE_GAME_SEED`) so runs are reproducible and bounded; fail with a clear error if the
  feature has not occurred by a hard turn cap.
- Minimum 20 completed turns in journey 1.
- Screenshots at every step; console/page errors fail the test.
- Scripted opponents are allowed only if added through the lobby UI (the fake-provider and scripted
  catalog entries available under test mode); no direct API calls.
- A lint/grep check in the suite fails if journey files import API helpers or call `fetch`/`request`.

## Acceptance Criteria

- [ ] All six journeys pass against real servers.
- [ ] Each journey's first navigation is the home page URL.
- [ ] Journey 1 includes a merger and a trade, shown by screenshots.
- [ ] Static check forbids `/api/`, `/test/`, `request.`, `fetch(` in journey files.
- [ ] Each journey is named in the surface coverage map for the surfaces it touches.
- [ ] Whole tier finishes in under 10 minutes locally.
