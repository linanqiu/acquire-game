# TP-003: Tier-2 Protocol Suite

## Metadata
- **Epic**: [Test Pyramid](../../epics/11-test-pyramid.md)
- **Status**: `in-progress`
- **Priority**: `high`
- **Effort**: `L` (2-4h)
- **Dependencies**: TP-002

## Context

Most "does the server hold together" bugs do not need a browser. Tier 2 drives the real FastAPI app
in-process (HTTP + WebSocket test clients) with scripted seats. Runs in `pytest backend/tests -q`.

## Requirements

- Full games over the real HTTP/WS protocol, 3-6 seats, mixes of human-style clients and scripted
  and fake-LLM seats, ending in game over.
- Scenarios: create/join/add-seat/start; full game to game over; **reconnect** (drop and reopen a
  WebSocket mid-turn and mid-merger, receive current state and `awaiting`); duplicate name; full
  room; bad room code; start with too few players; actions out of turn; trade round trip (human
  <-> scripted, human <-> fake LLM); host/spectator connection receives updates and cannot act;
  concurrent actions from several clients (lock behaviour); remove-seat in lobby.
- Message ordering and shape asserted against the types the frontend uses.
- Whole tier runs in seconds, and is part of the normal `pytest backend/tests -q`.

## Acceptance Criteria

- [x] At least 3 full games (different seat mixes) complete over the real protocol.
- [ ] Reconnect scenarios covered for each blocking decision kind.
- [ ] Every error path in the lobby journey list (bad code, duplicate name, full room) has a protocol test whose message text matches what the UI displays.
- [ ] No sleeps longer than a few hundred ms; conditions are awaited, not slept.
- [x] Tier completes in under 30 s locally.

**Status note (2026-11-14):** `backend/tests/protocol/` (52 tests, about 13 s) covers 3 full
games (human + scripted seats; all-agent game with failing LLM seats; all-heuristic determinism),
driver timeouts, concurrency, snapshot loading, seat routes and trade notifications. Not yet
covered: reconnect for each blocking decision kind (one reconnect test and a pending-prompt-on-
connect test exist) and protocol tests for the lobby error paths (bad room code, duplicate name,
full room) with UI text matching. Sleep use not audited.

## Verification

```bash
pytest backend/tests -q -k protocol
```
