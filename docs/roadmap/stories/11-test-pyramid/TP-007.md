# TP-007: Retire/Trim the Old Scenario Suite

## Metadata
- **Epic**: [Test Pyramid](../../epics/11-test-pyramid.md)
- **Status**: `complete`
- **Priority**: `medium`
- **Effort**: `M` (1-2h)
- **Dependencies**: TP-004, TP-005

## Context

The old Playwright scenario suite (62 tests, about 9,300 lines) did not finish in 10 minutes. Most
of it re-verifies rules through the browser by playing 20-40 turns against live bots. Rules are now
tested once, in tier 1.

## Requirements

- For each old scenario test, decide: (a) covered by a tier-1/2 test; (b) becomes a tier-3 screen
  test; (c) folded into a tier-4 journey; (d) delete. Record the decision in a table in this story.
- Do not delete a scenario until the surface or rule it covered has a replacement test, named in
  the table. Rules the scenarios covered but tier 1 does not must get a tier-1 test first.
- Remove obsolete helpers; keep shared helpers (screenshots, console capture) that tiers 3-4 use.
- Mark ST-001..ST-009 and ST-011 notes accordingly; Epic 7 doc points to Epic 11.

## Acceptance Criteria

- [x] Disposition table for all 90 legacy tests (62 scenario tests and 28 top-level ones) is in [docs/tests/legacy-suite-retirement.md](../../../tests/legacy-suite-retirement.md): covered, not worth covering, and gaps (each gap now has a test).
- [x] Old suite removed (about 10,500 lines, the `legacy` Playwright project, `e2e:legacy`, dead helpers and `fixtures/tile-sequences`); `npm run e2e` runs screens, journeys and transcripts; `e2e:ci` runs the `@ci` journeys.
- [x] Total Playwright runtime (screens + journeys) is under 15 minutes locally: about 2.2 + 1.4 minutes (plus 2 minutes for the transcripts journey).
- [x] Surface coverage map shows no surface that lost coverage (`scripts/check-surface-coverage.py`).
