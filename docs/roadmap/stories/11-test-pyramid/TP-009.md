# TP-009: Remaining Browser-Test Gaps (follow-up to TP-004/TP-006)

## Context

The surface coverage map ([docs/tests/surface-coverage.md](../../../tests/surface-coverage.md))
ends with a few `GAP:` rows that no browser test reaches. None is a rule; all are display states.
`scripts/check-surface-coverage.py` lists them on every run.

## Requirements

- **Thinking indicator in a screen test** (PG-12, HO-05). Give the test-mode fake LLM seat a delay
  (for example `GAME_FAKE_LLM_DELAY`, read where `FakeProvider(model="fake")` is built in
  `backend/agents/llm/config.py`; `FakeProvider` already has a `delay` argument), then assert
  `ai-thinking` appears while the seat decides and goes away when it has played. Journeys J1 and J4
  already see the indicator, so this only adds a stable, fast check.
- **BOT ASSIST marker** (PG-21): a test-mode fake LLM that answers illegally a fixed number of times,
  so a seat falls back to the bot and `seat-fallback-*` shows in the players panel.
- **LOAD MORE** on the games list (TX-04), **replay play/pause and speed** (TX-08), **leaderboard
  protocol and prompt-version selectors** (BN-03): drive them once from the transcripts spec.

## Acceptance Criteria

- [ ] PG-12 and HO-05 name a screen test; PG-21 names a browser test.
- [ ] TX-04, TX-08, BN-03 name a test or keep a dated reason.
- [ ] `python scripts/check-surface-coverage.py` reports fewer gaps.
