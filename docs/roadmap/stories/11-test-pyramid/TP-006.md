# TP-006: Surface Coverage Map (supersedes ST-010)

## Metadata
- **Epic**: [Test Pyramid](../../epics/11-test-pyramid.md)
- **Status**: `complete`
- **Priority**: `high`
- **Effort**: `M` (1-2h)
- **Dependencies**: None to create; filling the "covered by" column needs TP-004/TP-005

## Context

[ST-010](../07-scenario-tests/ST-010.md) mapped scenario ids to test files and reported percentages
per scenario category. That counts tests, not what users can see. It is replaced by a map of
**surfaces**.

## Requirements

- [docs/tests/surface-coverage.md](../../../tests/surface-coverage.md) lists every user-visible
  surface: every route/page, every entry point on the home page, every game phase screen, every
  modal, every error state, each for player and host views where they differ.
- Each row has: surface id, description, how to reach it, **covered by** (journey and/or screen
  test, as `file:test name`), tier, and status.
- A check script (`scripts/check-surface-coverage.py` or a Vitest/Node test) that:
  - fails if a row's "covered by" names a test that does not exist;
  - prints the uncovered surfaces (a visible gap list);
  - fails if a route in `frontend/src/App.tsx` or a page-level `data-testid` entry point is missing from the table.
- Adding a surface (new route, modal, phase, error state) requires adding a row; reviewers check it.
- Coverage is reported as "N of M surfaces covered; K journeys" - not line or scenario percentage.

## Acceptance Criteria

- [x] Skeleton exists and enumerates the surfaces found in `App.tsx`, `pages/*.tsx`, `components/game/` (initial version done 2026-11-14).
- [x] Check script runs in CI and lists gaps (`scripts/check-surface-coverage.py`, in the `lint` job and in `scripts/verify-change.sh`). It fails on an empty cell without `GAP:`, a unit-only row without `GAP:`, a reference to a test that no longer exists, a route of `App.tsx` missing from the map, a page or component with a `data-testid` not named in the map, and stale summary counts.
- [x] Every row is covered or carries an explicit reason and a follow-up story ([TP-009](TP-009.md)): 112 of 117 surfaces covered by a browser or protocol test; 7 `GAP:` rows (5 surfaces with no browser test, 2 whose screen-tier test is missing but a journey covers them).
