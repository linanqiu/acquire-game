# TP-008: CI Wiring

## Metadata
- **Epic**: [Test Pyramid](../../epics/11-test-pyramid.md)
- **Status**: `in-progress`
- **Priority**: `medium`
- **Effort**: `M` (1-2h)
- **Dependencies**: TP-003, TP-004, TP-005

## Context

GitHub CI today runs ruff lint, ruff format check, and pytest with coverage. The new tiers and the
surface check need jobs.

## Requirements

- Job 1 (every push): ruff lint + format check, `pytest backend/tests -q` (tiers 1 and 2, including
  the snapshot provenance test), frontend lint/typecheck/unit tests.
- Job 2 (every push): `npm run e2e:screens` with `ACQUIRE_TEST_MODE=1`, servers started in the job.
- Job 3 (every push or nightly, owner to choose when runtime is known): `npm run e2e:journeys`.
- Surface coverage check (TP-006) runs in job 1.
- Playwright screenshots and traces uploaded as artifacts on failure and on journeys always.
- `ACQUIRE_TEST_MODE` is set only in test jobs; a check ensures deploy config does not set it.

## Acceptance Criteria

- [ ] All jobs green on a clean branch.
- [ ] A deliberately broken snapshot fixture fails job 1.
- [ ] Artifacts contain screenshots for failing and journey runs.
- [ ] Wall-clock time per job is recorded in the PR description.

## Verification

Open a PR and read the workflow run; locally `./scripts/verify-full.sh`.
