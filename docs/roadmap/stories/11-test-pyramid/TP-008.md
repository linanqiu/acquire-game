# TP-008: CI Wiring

## Metadata
- **Epic**: [Test Pyramid](../../epics/11-test-pyramid.md)
- **Status**: `in-progress`
- **Priority**: `medium`
- **Effort**: `M` (1-2h)
- **Dependencies**: TP-003, TP-004, TP-005

## Context

GitHub CI today runs ruff lint, ruff format check, and pytest with coverage. The new tiers and the
surface check need jobs.

## Requirements

- Job 1 (every push): ruff lint + format check, `pytest backend/tests -q` (tiers 1 and 2, including
  the snapshot provenance test), frontend lint/typecheck/unit tests.
- Job 2 (every push): `npm run e2e:screens` with `GAME_TEST_MODE=1`, servers started in the job.
- Job 3 (every push or nightly, owner to choose when runtime is known): `npm run e2e:journeys`.
- Surface coverage check (TP-006) runs in job 1.
- Playwright screenshots and traces uploaded as artifacts on failure and on journeys always.
- `GAME_TEST_MODE` is set only in test jobs; a check ensures deploy config does not set it.

## Status note (2026-11-14)

`.github/workflows/ci.yml`: `lint` runs ruff and `scripts/check-surface-coverage.py`; `frontend-lint`
runs typecheck, lint and Vitest; `test` runs pytest (including the provenance test) as before; `e2e`
is a three-way matrix (`screens`, `journeys`, `transcripts`) running in parallel, each starting its
own servers through the Playwright `webServer` config (`GAME_TEST_MODE=1` only there), with
`--trace off`, uploading `frontend/test-results` and the HTML report on failure (journeys: always).
Checked locally: the commands of every job, and that a hand-edited snapshot fixture fails
`pytest backend/tests/test_fixture_provenance.py`. Not checkable without a pull request: green
runs on GitHub and per-job wall-clock times (locally: screens 2.3 min, journeys 1.4 min, transcripts
1.9 min, with 4 workers; CI uses `workers: 1` and `retries: 2` per `playwright.config.ts`).

## Acceptance Criteria
